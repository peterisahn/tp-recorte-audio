# TD V - Diseño de Algoritmos: *TP Recorte de Audio*

Repositorio con la **implementación, experimentación** y **análisis comparativo** del problema de *Recorte de Audio* para la materia TD V.

## Contenido

- **Implementación en C++**:
  - Fuerza Bruta: Exploración exhaustiva de todas las posibles soluciones.
  - Backtracking: Optimización recursiva usando podas por optimalidad.
  - Programación Dinámica: Enfoque eficiente reconstruyendo la solución (representada en índices de pulsos) óptima.
- **Implementaciones en Python**:
  - Re-implementación de las estrategias de Backtracking y Programación Dinámica.
- **Modos de Ejecución**:
  - Modo Numérico: Procesamiento de matrices en archivos de texto plano (txt).
